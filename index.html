01. featured projects

argon · desktop app · typescript, electron

a board for running coding agents together on windows. claude code, codex and gemini run in real terminals side by side, grouped into teams that plan, build and review, handing work to each other along wires. a simple chat view for each agent, memory meters, loops, and a liquid glass ui with accents, palettes and mica.

electron · react flow · node-pty · claude code · liquid glass — website · source

salt · client · rust, java

a clean, glassy minecraft client built with tauri. ships its own fabric hud (saltHUD), a set of saltMODs, performance mods out of the box, modrinth + curseforge, skins & capes, friends & chat, and every release from 1.21 to 26.3.

tauri · fabric · microsoft auth · 1.21 → 26.3 — website · source

chlorine · mod · java

a fabric performance & power-management mod for mc 26.3 that runs alongside sodium. adaptive simulation distance, entity & particle scaling, a fast-travel chunk governor, and distant mob ai throttling.

fabric · sodium-compatible · 26.3 — website · source

cornea · shaderpack · glsl

a photon-inspired iris shaderpack for mc 26.x, tuned for mid/low-end gpus. physically based sky, volumetric clouds, coloured block lights, godrays, and proper water.

iris · volumetrics · made with ai — website · source

facet · web app · javascript

a speedcubing timer with a liquid glass ui. wca scrambles for 16 events, wca inspection & timing rules, stats widgets, and cstimer import. no build step.

speedcubing · web worker · liquid glass — try it · source
